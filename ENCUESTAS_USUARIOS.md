## 📝 Plantilla de Encuesta

### Sección 1: Información del Usuario
1. Nombre
2. Relación con el evaluador
3. Edad
4. Nivel de experiencia con tecnología (Bajo/Medio/Alto)

### Sección 2: Tareas a Realizar
1. Iniciar sesión en el sistema
2. Navegar por los cursos disponibles
3. Seleccionar un curso y ver sus asignaturas
4. Seleccionar una asignatura y ver los resultados de aprendizaje
5. Visualizar los criterios de evaluación de un RA
6. Cerrar sesión

### Sección 3: Escala de Usabilidad del Sistema (SUS)
Escala de 1 (Totalmente en desacuerdo) a 5 (Totalmente de acuerdo)

1. Creo que me gustaría usar este sistema frecuentemente
2. Encontré el sistema innecesariamente complejo
3. Pensé que el sistema era fácil de usar
4. Creo que necesitaría ayuda de una persona técnica para usar este sistema
5. Encontré que las diversas funciones del sistema estaban bien integradas
6. Pensé que había demasiada inconsistencia en este sistema
7. Imagino que la mayoría de las personas aprenderían a usar este sistema rápidamente
8. Encontré el sistema muy incómodo de usar
9. Me sentí muy seguro/a usando el sistema
10. Necesité aprender muchas cosas antes de poder empezar con este sistema

### Sección 4: Preguntas Abiertas
1. ¿Qué fue lo que más te gustó del sistema?
2. ¿Qué fue lo que menos te gustó?
3. ¿Encontraste algún error o problema?
4. ¿Qué mejorarías?
5. ¿Recomendarías este sistema? ¿Por qué?

## 💡 Insights Clave

### Fortalezas Identificadas

1. **Claridad Jerárquica** (mencionada por 7/8 usuarios)
   - La estructura curso → asignatura → RA → criterios es intuitiva
   - Refleja perfectamente la organización curricular de FP

2. **Facilidad de Uso** (puntuación promedio: 4.25/5)
   - Interfaz intuitiva para usuarios con experiencia media-alta
   - Curva de aprendizaje rápida

3. **Diseño Profesional** (mencionado por 5/8 usuarios)
   - Aspecto moderno y limpio
   - Responsive design funciona bien

4. **Rendimiento** (mencionado por 3/8 usuarios)
   - Carga rápida de datos
   - Navegación fluida

### Áreas de Mejora

1. **Accesibilidad para Usuarios Menos Técnicos**
   - Usuario con baja experiencia tecnológica tuvo dificultades
   - Necesidad de tooltips y tutorial inicial

2. **Funcionalidades Adicionales**
   - Exportación a PDF/informes (mencionado por 4 usuarios)
   - Sistema de notas personales (mencionado por 2 usuarios)
   - Gestión de años académicos (mencionado por 1 usuario)

3. **Feedback Visual**
   - Indicadores de carga más prominentes
   - Más feedback en interacciones

4. **Personalización**
   - Modo oscuro (mencionado por 1 usuario)
   - Temas personalizables (mencionado por 1 usuario)

## 🎯 Recomendaciones Prioritarias

### Prioridad Alta
1. ✅ **Tutorial inicial o tour guiado** - Para mejorar onboarding
2. ✅ **Tooltips explicativos** - Especialmente para términos técnicos como "RA"
3. ✅ **Indicadores de carga** - Mejorar feedback visual

### Prioridad Media
4. **Exportación a PDF** - Funcionalidad muy solicitada
5. **Vista de resumen** - Ver todos los RAs de un curso
6. **Búsqueda de criterios** - Facilitar navegación en cursos grandes

### Prioridad Baja
7. **Modo oscuro** - Mejora estética
8. **Sistema de notas** - Funcionalidad adicional para estudiantes
9. **Integración con Moodle** - Para adopción institucional

## 📎 Anexos

### Metodología de Cálculo SUS

La puntuación SUS se calcula de la siguiente manera:

1. Para preguntas impares (1, 3, 5, 7, 9): Restar 1 de la puntuación del usuario
2. Para preguntas pares (2, 4, 6, 8, 10): Restar la puntuación del usuario de 5
3. Sumar todos los valores convertidos
4. Multiplicar por 2.5

Resultado: Puntuación de 0 a 100
